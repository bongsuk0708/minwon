처음 한 번 — 설치하고 이름 넣기

한 번만 하면 됩니다

주소: bongsuk0708.github.io/minwon/risk

  1. 크롬으로 위 주소를 엽니다. (카카오톡 안에서 열면 설치가 안 됩니다)
  2. 오른쪽 위 ⋮ → 앱 설치 또는 홈 화면에 추가를 누릅니다.
    삼성 인터넷: 아래 ≡ → 현재 페이지 추가 → 홈 화면
    아이폰(사파리): 아래 공유 ⬆ → 홈 화면에 추가
  3. 폰 바탕화면에 위험성평가 아이콘이 생깁니다. 다음부터 이 아이콘으로 엽니다.
  4. 크롬이나 엣지로 위 주소를 엽니다.
  5. 주소창 오른쪽 끝의 설치 ⊕ 아이콘을 누르면 바탕화면에 아이콘이 생깁니다. 아이콘이 없으면 Ctrl + D로 즐겨찾기에 넣어도 됩니다.
  6. 처음 열면 이름 넣는 창이 뜹니다. 본인 이름을 적습니다. 저장·처리할 때 이 이름이 남습니다.
  7. 이름을 바꾸려면 화면 오른쪽 위 주황색 이름을 누릅니다.
인터넷이 연결되어 있어야 저장됩니다. 신호가 약한 곳에서는 밖으로 나와서 저장하세요.

사진·파일 올리는 법

보고·평가표·교육·포상·서류 등 모든 화면이 똑같습니다
  1. 📷 사진 찍기 — 카메라가 바로 켜집니다. 찍으면 붙습니다.
  2. 🖼 고르기 — 이미 찍어 둔 사진이나 PDF를 갤러리·내 파일에서 고릅니다. 여러 장을 한 번에 골라도 됩니다.
  3. 📁 파일 고르기 — PC에 있는 사진(jpg·png)이나 스캔한 PDF를 고릅니다. Ctrl을 누른 채 여러 개를 고를 수 있습니다.
  4. 잘못 고른 것은 × 또는 빼기를 누릅니다.
  5. 마지막에 그 화면의 저장 버튼을 눌러야 올라갑니다.
PDF는 한 개에 8MB까지 올라갑니다. 사진은 자동으로 줄여서 올립니다.

아차 위험 보고하기 — 「아차위험접수」 앱

현장 직원용 앱은 따로 있습니다 · 다칠 뻔했거나 위험한 곳을 봤을 때

주소: bongsuk0708.github.io/minwon/risk/bogo/
관리자 앱 › 📥 접수함 맨 위 주소 복사를 눌러 카톡·밴드로 보내 주세요. 처음 열면 설치 안내가 나옵니다.

  1. 아차사고(다칠 뻔한 일) 또는 위험요인(위험한 장소·장비)을 고릅니다.
  2. 언제 있었는지, 이름, 장소(동·주소·위치)를 적습니다.
  3. 무슨 일이었는지 한두 줄 적습니다. 짧아도 됩니다.
  4. 📷 사진을 찍어 붙입니다.
  5. 이름을 숨기고 싶으면 이름 숨기기에 체크합니다.
  6. 보고하기를 누르면 끝. 관리자 앱 접수함으로 바로 들어갑니다.
보고는 벌점이 아니라 사고를 막는 기록입니다. 작은 것도 올려 주세요.
관리자

① 접수함 — 들어온 보고 처리

홈 › 📥 접수함 (버튼에 처리 대기 건수가 나옵니다)
  1. 목록에서 보고를 누릅니다.
  2. 상태를 바꿉니다: 접수 → 검토중 → 평가 반영 → 조치완료
  3. 조치 내용에 한 일을 적습니다. (예: 바닥 미끄럼 방지 매트 설치)
  4. 조치 사진·파일: 고친 뒤 사진이나 서류를 올립니다. (📷 사진 찍기)(📁 파일 고르기)
  5. 저장. 누가 언제 바꿨는지 처리 이력에 남습니다.
위험성 평가가 필요한 건이면 평가표로 보내기 → 내용과 사진이 채워진 수시평가 화면이 열립니다.
잘못 들어온 보고는 맨 아래 🗑 이 보고 삭제 (기록은 남습니다).
아차사고를 알려 준 직원은 🏆 신고자를 포상 추천으로 바로 추천할 수 있습니다.

② 교육·TBM 기록

홈 › 👥 교육·TBM 기록
  1. 구분(TBM · 정기 안전교육 · 위험성평가 교육), 제목, 날짜, 장소를 넣습니다.
  2. 교육 내용이나 오늘의 위험요인을 한 줄에 하나씩 적습니다.
  3. 교육 사진을 붙입니다.
  4. 서명은 둘 중 하나로 받습니다.
    · 폰 서명: + 폰으로 서명 → 폰을 돌려 한 명씩 이름 적고 손가락으로 서명
     · 종이 서명지: 빈 서명지를 인쇄해 사인받고 → 📷 사진 찍기로스캔한 PDF를 📁 파일 고르기로 올리기 (서명지에 이름·사인이 있어서 명단은 따로 안 넣어도 됩니다)
  5. 저장. 저장된 기록에서 교육 실행서 인쇄 / PDF를 누르면 사진·서명까지 한 장으로 나옵니다.

③ 현장 체크리스트 점검

메뉴 › ✅ 점검
  1. 점검할 공정(예: 음식물류폐기물)을 누릅니다.
  2. 항목마다 적합 / 부적합 / 해당없음을 누릅니다.
  3. 부적합이면 무엇이 문제인지 적고 사진을 붙입니다.
  4. 나머지가 다 괜찮으면 남은 항목 모두 적합 → 점검 저장.
  5. 결과 화면에서 부적합 항목은 평가표로 보내기, 종이가 필요하면 인쇄 / PDF.
점검 항목을 바꾸려면 공정 옆 ✏ 항목. 새 점검표는 + 새 체크리스트 만들기.

④ 평가표 보기·고치기·인쇄

메뉴 › 📊 평가
  1. 위에서 연도를 고릅니다. (2026은 보관본이라 고칠 수 없습니다)
  2. 정기 / 수시로 나눠 보거나, 검색창에 낱말(예: 후진, 사각)을 넣어 찾습니다.
  3. 항목을 누르면 위험성, 감소대책, 예정일·완료일, 수정 이력이 나옵니다. 수정으로 고칩니다.
  4. 새 위험(사고·작업 변경·새 장비)이 생기면 + 항목 추가 = 수시평가.
  5. 인쇄: KRAS 양식(A4 가로)으로 나옵니다. PDF로 저장하려면 인쇄 창에서 프린터를 「PDF로 저장」으로 고르세요.폰은 인쇄 창에서 「PDF로 저장」을 고르면 파일로 남습니다.

⑤ 새해 정기평가 시작하기

1년에 한 번 · 이미 만든 해는 평가 메뉴에서 그 연도를 누르면 됩니다
  1. 홈 › 다음 정기평가 시작하기 (또는 평가 › + 새 연도)
  2. 가져올 평가표에서 작년을 고르고, 평가 시작일·종료일을 넣습니다.
  3. 평가표 만들기 → 작년 항목이 그대로 들어옵니다. (점수는 그대로, 예정일·완료일은 비어서 들어옵니다)
  4. 평가 › 그 연도에서 항목을 하나씩 열어 수정 → 올해 상황에 맞게 위험성·감소대책을 고치고 예정일·완료일을 넣습니다.
완료일을 넣은 항목은 홈 조치 필요에서 빠집니다. 완료일이 평가일보다 앞서면 경고가 뜨고 저장되지 않습니다.

⑥ 대표 사인 받은 서류 올리기

홈 › 📤 서류 올리기 · 실시규정, 사전준비 회의, 추진 일정, 안전·보건 예산 등
  1. 서류를 출력해서 대표님 사인을 받습니다.
  2. 📷 사진 찍기로 서류를 찍습니다. (평평한 곳에 놓고 위에서 똑바로)
  3. 스캔한 PDF나 사진을 📁 파일 고르기로 고릅니다.
  4. 어떤 서류예요?에서 종류를 고릅니다. (파일 이름에 「예산」「규정」「일정」「회의」가 있으면 미리 골라져 있습니다)
  5. ⬆ 저장 → 기록 › 1단계 · 사전준비의 그 칸에 연도별로 들어갑니다.
기록 › 1단계 · 사전준비 화면에서 칸마다 바로 올릴 수도 있습니다. 서류 이름을 누르면 열리고, 잘못 올린 것은 빼기.

이럴 땐 이렇게

앱이 예전 화면 그대로예요 앱을 완전히 닫았다가(최근 앱 목록에서 위로 밀기) 다시 여세요. 그래도 안 바뀌면 한 번 더.키보드 Ctrl + F5를 누르세요. 지금 버전은 홈 맨 위(예: v20)에 나옵니다. 📷 사진 찍기를 눌러도 카메라가 안 켜져요 폰 설정 › 애플리케이션 › 크롬(또는 위험성평가) › 권한 › 카메라 허용. 안 되면 🖼 고르기로 찍어 둔 사진을 올리세요. 저장 실패라고 나와요 인터넷 연결을 확인하고 다시 누르세요. 적은 내용은 화면에 그대로 남아 있습니다. 잘못 저장했어요 평가 항목은 수정으로 고칩니다(이력이 남음). 보고는 접수함에서 상태·조치 내용을 바꾸거나 삭제합니다. 서류는 빼기. 이름이 다른 사람으로 나와요 오른쪽 위 주황색 이름을 눌러 바꾸세요. 같이 쓰는 폰·PC면 쓰기 전에 이름을 꼭 확인하세요. 설치 버튼이 안 보여요 카카오톡·밴드 안에서 열면 설치가 안 됩니다. 주소를 크롬(또는 삼성 인터넷)에서 다시 여세요.
